# Energy Consumption Analysis

A modular Python project for exploring hourly energy consumption. The sample dataset is synthetic and is for practice; it does not represent real meter readings.

## Dataset

Run the generator to create 60 days of hourly sample data (1,440 records):

```powershell
python generate_sample_data.py
```
## Open the interactive dashboard

From the project folder, run:

```powershell
streamlit run app.py
```
